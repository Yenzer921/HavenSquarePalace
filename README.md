# HavenSquare Palace — Hotel Reservation Website

A responsive, multi-page website for a fictional boutique hotel near Times Square, New York.
Built as a group project (Group 28) at Sunway University.

**Live demo:** https://yenzer921.github.io/HavenSquarePalace/

**Tech:** HTML · CSS · JavaScript (no frameworks, no backend)

## Features

- **Home** with hotel attractions and operating hours
- **Services** with five room types (Urban Suite, Garden Villa, Skyline Penthouse, Seaside Retreat, Heritage Loft) and facilities and amenities
- **Booking confirmation** that reads the stay details from the URL and calculates the number of nights and the total price
- **Restaurant menu**
- **About** with the hotel's history, nearby NYC attractions, transport info, guest reviews and the team
- **Contact form** with client-side validation
- **Sign up / log in** with form validation (password strength, matching passwords, email domain checks), with accounts stored in the browser's `localStorage`

## Run it

Visit the live demo, or open `index.html` in any browser. No install needed.

## Project structure

```

├── services.html       Rooms and facilities

├── contact.html        Contact form
├── signup.html / login.html

└── images/
```
